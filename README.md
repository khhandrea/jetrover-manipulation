# JetRover Manipulation

A manipulation framework for Hiwonder JetRover Jetson Orin Nano version.

This repository contains packages and scripts for controlling the 6-DOF robotic arm on the JetRover, integrated with custom manipulation algorithms (e.g., Inverse Kinematics, Teleoperation, or Learning-based policies).

![ROS2 Humble](https://img.shields.io/badge/ROS2-Humble-blue)
![Platform](https://img.shields.io/badge/Platform-Jetson_Orin_Nano-green)

## Prerequisites

* Operating System: Ubuntu 20.04 (JetPack 5.x)
* ROS Version: ROS 2 Humble Hawksbill
* Dependencies:
    * Hiwonder SDK (pre-installed on JetRover)
    * Python libraries: `numpy`, `scipy`, `opencv-python`

## Installation

```bash
cd ~/ros2_ws/src
git clone [https://github.com/khhandrea/jetrover-manipulation.git](https://github.com/khhandrea/jetrover-manipulation.git)
```
